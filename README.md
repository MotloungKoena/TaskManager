# TaskManager - Team Task Management with Real-time Chat

A full-stack task management application with real-time messaging, read receipts, and team collaboration.

## Tech Stack
- **Backend:** ASP.NET Core Web API, SignalR, Entity Framework Core
- **Frontend:** React, Tailwind CSS
- **Database:** SQL Server
- **Real-time:** SignalR

## Features
- ✅ Project & Task Management
- ✅ Real-time Chat with Read Receipts
- ✅ Online/Offline Status
- ✅ Profile Pictures
- ✅ Role-based Access Control
